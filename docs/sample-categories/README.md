# Sample category content

Create these four categories manually in the admin. No records have been inserted.
`categories.json` contains form values plus `image_file`, `image_alt` and
`image_source` reference metadata; those three fields are not API payload fields.
Upload each JPG through the image control and enter its alt text before saving.
The form obtains the real managed media ID automatically. Do not POST local paths
or external photo URLs in `images`.

Keep Active selected. Featured collection is optional: select it after supplying
the description and image to show a homepage collection card. These are sample
stock photographs for testing; use your own category photography before launch.
Source links for the Unsplash photographs are included in the JSON.
